# WhatThePort 中英汉化开发日志

日期：2026-09-26  
状态：本机可用，尚未上传 GitHub，尚未公开发行。

## 目标和判断

希望用中文查看本机开发服务的端口、项目、分支和内存情况。上游当时没有中文资源或语言选择，决定在原项目上增加中英支持，保持原有进程管理行为。

上游：https://github.com/tomjohndesign/what-the-port 。基线为 28493cc。README 声明 MIT，但检查仓库未找到独立完整 LICENSE；公开再分发前应向作者确认并补齐许可材料，不能自行替原作者填写版权声明。

## 实现

- 整理 292 条原生界面文案，采用 en / zh-Hans 的标准 Localizable.strings。
- 设置支持跟随系统、简体中文、English，保存后重启生效。
- 覆盖列表、详情、设置、首次引导、菜单、帮助、无障碍和通知文案。项目名、路径、命令和品牌不翻译；CLI/TUI 与 JSON 保持英文和既有字段。
- 本地构建使用独立应用标识，移除官方更新源，防止汉化版被上游更新覆盖。
- 修复 SwiftPM 翻译资源的实际加载路径与语言目录大小写问题，避免在开发目录能运行、移到别处却找不到中文。
- 修复截图工具无法捕获原生列表的问题，改用已有 AppKit 窗口捕获，不改产品布局。

## 验证

原有和新增共 15 项测试通过。移开源码构建目录的翻译资源后，应用仍能独立生成中英文视图，各 18 张。检查中文列表、详情与引导，无明显截断。

在真实界面选择英文，重启后英文生效，再改回中文并重启验证。专用测试服务器在列表出现，能打开详情；点击停止后进程退出、端口关闭、列表对应项消失。测试没有停止其他项目。

Release 构建及深层签名验证通过。当前属于本地 ad-hoc 签名构建，未完成 Developer ID 公证；系统通知未授权实发，跨设备安装与长期使用尚未验证。
